An OMP plugin that connects Oh My Pi to an existing OmniRoute gateway.

Your OmniRoute models. Right inside Oh My Pi.

Connect the AI setup you already have to the coding assistant you want to use.

Your provider setup already lives in OmniRoute. Now you can use the models it exposes from inside Oh My Pi, without configuring every underlying provider again in your coding client. OMP OmniRoute Provider connects the two with guided setup and live model discovery.

## Facebook business post

You already set up your AI providers. Why set them up all over again just to use another coding assistant?

## Short listing description

Use your existing OmniRoute gateway from Oh My Pi. This OMP plugin provides guided connection setup, discovers available chat models, and offers optional model information, pricing views, and selected administration with review and confirmation. An existing gateway and runtime access key are required.

## Support prompt for an issue form

Tell us the plugin version, your OMP version, the command you used, and the error message after removing private details. Do not include access keys, cookies, your gateway hostname, account information, or private workspace paths.

## Empty-state wording for a future approved UI change

The lines below are copy proposals, not features implemented by this pack.

**No gateway connected:** Connect your OmniRoute gateway to see its available models.

**Key accepted, no compatible chat models:** Your key was accepted, but this gateway is not exposing a compatible chat model to this connection.

**Catalog unavailable:** Extra model information is unavailable. Your gateway connection can still work.

**Administration unavailable:** This operation is not available in the current qualified set. Check the administration guide for its status.

## Phrases that must not be added without new evidence

“Official OmniRoute plugin,” “all models,” “full dashboard control,” “unlimited free AI,” “zero data leaves your computer,” “guaranteed savings,” “works on every platform,” and “latest-version screenshots” are not approved claims.
