# Support

Start with the [first-use guide](docs/first-use.md) and
[troubleshooting](docs/troubleshooting.md). Include the client, OMP, and OmniRoute
versions and your operating system when reporting a reproducible client problem.
Search existing issues before opening a report.

Use disposable data and placeholders. Remove credentials, cookies, prompts, account
identifiers, private endpoints, and local paths from screenshots and logs. Send
security reports through the repository's private Security channel as described
in [SECURITY.md](SECURITY.md).

The client connects OMP to an existing OmniRoute server. Server availability,
provider accounts, and upstream billing remain the responsibility of their owners.
